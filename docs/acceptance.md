## 자동 검증

실제 PostgreSQL과 Payload 인증을 사용하는 독립 시험 DB를 포함한 자동시험 25개 통과(2026-11-19). 단일 사진 프로젝트 발행과 권리 미확인 거부를 추가 검증했습니다. 익명·직원 권한, 정확한 버전 발행과 충돌, 초안·공개본 분리, 복구·비공개·slug 변경, 원본·초안 미디어 차단, 업로드 형식·용량·EXIF, 문의+알림 원자성, 동시 중복 제출, DB 장애 롤백, 메일 재시도·작업자 경쟁, 보유기간 삭제, 세션 폐기를 검사했다. 사용자 요청에 따른 위치·작업유형 생략 발행, 직접 업로드 권한, 예약 작업 인증도 검증했다.

`pnpm typecheck`, `pnpm build`와 실제 Vercel Node24 빌드를 통과했다. 운영 서버에서도 관리자 로그인, 직접 업로드·미사용 시험 사진 삭제, 원본·비공개 사진 차단, 로그아웃 세션 폐기 등16개 검사를 통과했다. 삼전동31장은 공개 HTTP 응답과 파일 체크섬을 모두 확인했다.

## 브라우저 검수

내장 브라우저에서 실제 UI로 확인했다. 홈 및 최종 프로젝트 목록의360·390·768·1440px 너비에서 문서 가로 넘침이 없다. 최종 목록의 grid gap은 모두0px. 상세의 대표사진→본문 및 본문 블록 간격은0px, 두 사진 사이도0px다. 제목·로고·이미지 크롭을 직접 확인했다.

더 보기로12→22개 표시, 상세 이동·뒤로 가기를 확인했다. 용도 필터는 정상 동작 검수 후 사용자의 제거 요청에 따라 최종 화면에서 삭제했다. 사진 클릭, 다음 사진, Escape 닫기, 원래 사진 버튼으로 초점 복귀를 확인했다. 모바일 메뉴, 문의 필드 오류·접수번호·관리자 조회, 관리자 로그인·자동 저장·재접속 저장 상태를 확인했다.

증거 화면은 `screenshots/`에 있다. 모바일 스와이프는 구현되었으나 실제 터치 기기에서 검수하지 않았다. 200% 브라우저 확대와 Chrome/Safari 각각의 전체 시나리오는 미검수다.

## 추가 운영 설정

호스팅·DB·비공개 저장소·대표 계정은 연결했다. 실제 업무 연락처, 검증된 메일 발신자·수신자, 개인정보 안내와 처리 업체, 최신 승인 로고 및 별도 도메인은 추가 확인 항목이다. 기존 DNS·MX는 변경하지 않았다. Docker 환경이 없어 Dockerfile 자체 빌드는 미검증이다. 무료 요금제를 유지하며 시험 메일을 실제 발송으로 표시하지 않는다.
